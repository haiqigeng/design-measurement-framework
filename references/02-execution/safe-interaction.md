# Safe Interaction

## Classify The Environment

Treat production, staging, sandbox, local, and design/prototype evidence
separately. Do not assume staging is current or authoritative merely because it
is safer. Resolve authority from the target state and record divergences.

Use production primarily for real content, routes, controls, and safe reversible
states. Use a confirmed non-production environment for consequential funnel
completion and backend outcomes.

## Safe Defaults

Use clearly synthetic, non-routable values when interaction is necessary.
Never retain credentials or synthetic personal values in the framework,
screenshots, logs, or chat summaries.

In production, do not:

- place or authorize a transaction;
- submit a lead or contact request that alerts a real team;
- create an account that triggers operational follow-up;
- send email, SMS, push, referral, invitation, or other communication;
- book an appointment, delivery, fulfilment, trial, contract, or service;
- delete, cancel, return, refund, or mutate a real record;
- bypass CAPTCHA, authentication, consent, or another protection;
- use real personal, payment, customer, employee, or credential data.

Inspect client-side validation and stop before the consequential action. Ask for
a safe environment or user description when the outcome cannot be observed
safely.

In a confirmed test/sandbox environment, complete ordinary synthetic flows only
when the environment and test mechanism are clearly established. Use provider-
documented sandbox payment values; never request or retain a real card number.

## Unblocking

Before marking a material state blocked:

1. try a relevant alternate entry point or route;
2. try the appropriate anonymous/authenticated or market variant when available;
3. verify that the blocker is not a sampling or automation limitation;
4. request the narrowest specific unblock;
5. accept credible user or technical description as confirmed evidence when
   direct observation remains impossible.

Record the attempted route, blocker, requested unblock, fallback evidence, and
impact. Do not let an unresolved production-safety boundary disappear from the
framework.
